# 蓝白错题本

一个面向学生的「错题收集 + 学习计划 + 专注倒计时」Web 应用：多文件原生前端，无构建工具、无 npm 依赖，数据全部保存在本机浏览器。

## 手机上安装使用（PWA）

项目已支持 PWA（渐进式 Web 应用），可在手机上像原生 App 一样安装、全屏运行与离线使用：

1. 用手机浏览器（Android Chrome / Edge，或 iOS Safari）打开应用的 HTTPS 公网地址；
2. 首次打开会出现「安装蓝白错题本」提示条：
   - **Android**：点击提示条上的「安装」按钮（或浏览器菜单 → 安装应用）；
   - **iOS**：点击 Safari 底部「分享」按钮 → 「添加到主屏幕」；
3. 桌面出现蓝底白勾的应用图标，点开即为全屏独立窗口，无浏览器地址栏；
4. 安装后**断网也能正常使用**（错题、计划、倒计时、提醒全部离线可用；仅 OCR 首次识别需联网加载语言模型，之后同样离线可用）。

> PWA 仅在 `http://localhost` 或 HTTPS 下生效；`file://` 直接打开不会注册 Service Worker。

## 启动方式

在项目根目录执行：

```bash
python3 -m http.server 8000
```

然后打开：

```
http://localhost:8000
```

> 必须通过静态服务器访问。直接双击 `index.html`（file:// 协议）会导致 ES Modules 与 IndexedDB 不可用。

## 单文件离线版

如果无法访问本地端口（例如通过云端网页端使用，没有端口转发或内置浏览器），可以直接使用
`蓝白错题本-离线版.html`：下载后用浏览器双击打开，无需服务器、无需端口。

- 数据保存在浏览器 localStorage，照片以 Base64 存储，容量有限（建议控制照片数量）。
- OCR 首次使用仍需联网加载语言模型，其余功能完全离线。
- 浏览器按文件路径区分本地数据，移动文件后可能读不到旧数据，请先用「设置 → 导出备份」迁移。
- 系统通知在 file:// 下可能不可用，届时自动降级为页面内弹窗提醒。

## 功能

- **错题本**：手动录入题目、答案、解析、错误原因、学科、知识点标签与难度。
- **拍照识别**：上传/拖拽/粘贴图片，自动压缩后保存；浏览器端 OCR 提取文字（Tesseract.js，中文 + 英文）。
- **分类管理**：按学科、复习状态、关键词筛选；内置学科可增删。
- **复习闭环**：待复习 → 复习中 → 已掌握，按 1 / 3 / 7 / 15 天的简单间隔生成下次复习日期。
- **学习计划**：添加任务（时间、时长、学科、优先级）、完成打钩、按日期/全部/已完成查看，历史计划永久保留。
- **闹钟提醒**：任务到点页面弹窗 + 提示音；授权浏览器通知后，切到后台也能收到系统通知。
- **专注倒计时**：15 / 25 / 45 分钟预设与自定义时长，开始、暂停、重置，结束提醒。
- **数据备份**：导出 JSON（含照片 Base64）、合并/覆盖导入、清空数据。

## 数据与隐私

- 错题、任务、图片存储在浏览器 **IndexedDB**（数据库名 `lanbai-cuoti`），轻量设置存储在 **localStorage**。
- 不上传任何数据到服务器，无登录、无第三方统计。
- 清除浏览器站点数据会清空全部记录，建议定期使用「设置 → 导出备份」。

## 已知限制

- **提醒依赖页面运行**：浏览器会对后台标签页的定时器节流，后台提醒可能延迟；关闭页面后不会触发提醒。
- **通知权限**：需要用户手动授权；被拒绝后需在浏览器站点设置中重新允许。未授权时降级为页面内弹窗。
- **OCR 需要联网**：首次识别会从 CDN（jsDelivr）加载 Tesseract.js 与中文语言模型；网络不可用时请手动输入文字。
- 图片单张建议不超过 12MB，保存前会压缩；存储空间不足时会提示清理。

## 目录结构

```
index.html
css/
  base.css          变量、基础重置
  layout.css        侧边栏、底部导航、页面栅格
  components.css    卡片、按钮、表单、弹窗、列表等组件
js/
  app.js            hash 路由与导航
  store.js          IndexedDB 封装与批量写入
  settings.js       学科与设置读写
  ocr.js            Tesseract.js 懒加载与识别
  remind.js         提醒调度、提示音、系统通知
  components/       modal、toast
  utils/            日期、转义与图标、图片压缩、复习算法
  views/            home、mistakes、plans、focus、settings
```

## 浏览器要求

支持 IndexedDB、ES Modules 与 `Notification` API 的现代浏览器（Chrome、Edge、Firefox、Safari 较新版本）。移动端以 360px 宽度起适配。
